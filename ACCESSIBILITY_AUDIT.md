# Accessibility Audit Report

This document outlines the findings of an accessibility audit conducted on the portfolio application. The audit was performed manually by reviewing the source code.

## Summary of Findings

The application has a good foundation for accessibility, but there are several areas that need improvement. The most critical issues are related to color contrast and the handling of reduced motion for animations.

## Keyboard Navigation

| Severity | Issue | Location | Recommendation |
| :--- | :--- | :--- | :--- |
| **Low** | No "skip to content" link. | `src/App.tsx` | A "skip to content" link should be added to allow keyboard users to bypass the navigation and go directly to the main content. |

## Reduced Motion

| Severity | Issue | Location | Recommendation |
| :--- | :--- | :--- | :--- |
| **High** | Framer Motion animations are not disabled when `prefers-reduced-motion` is enabled. | `src/App.tsx`, `src/components/ProjectsPage.tsx`, etc. | The `prefersReducedMotion` value from the `usePrefersReducedMotion` hook should be passed down to all components that use Framer Motion. The animations should then be conditionally disabled based on this value. |

## Screen Reader

| Severity | Issue | Location | Recommendation |
| :--- | :--- | :--- | :--- |
| **Medium** | Decorative video is not hidden from screen readers. | `src/App.tsx` | The background video is purely decorative and should be hidden from screen readers by adding the `aria-hidden="true"` attribute to the `<video>` element. |
| **Low** | Emojis in buttons are read by screen readers. | `src/App.tsx` | The emojis in the navigation buttons should be wrapped in a `<span>` with `aria-hidden="true"` to prevent them from being read out by screen readers. |
| **Low** | The "jewel" system lacks context for screen reader users. | `src/components/ProjectsPage.tsx` | The list of technologies could be presented in a more descriptive way for screen reader users. For example, instead of just listing the technology names, it could say "Technologies used: React, TypeScript, etc.". |

## ARIA Attributes

| Severity | Issue | Location | Recommendation |
| :--- | :--- | :--- | :--- |
| **Low** | Missing ARIA attributes for navigation. | `src/App.tsx` | The main navigation could be improved by adding ARIA attributes, such as `role="navigation"` and `aria-label="Main navigation"`. |
| **Low** | Missing ARIA attributes for project list. | `src/components/ProjectsPage.tsx` | The list of projects could be improved by adding `role="list"` to the container and `role="listitem"` to each project button. |
