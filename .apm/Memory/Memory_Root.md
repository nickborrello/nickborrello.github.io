## Phase 02 – Core Visual & Interactive Elements Summary
*   **Outcome:** Phase 2 built the core interactive shell of the application. A `LandingPage` and `MainLayout` were created to handle the initial view transition. A "zoom-in" animation was implemented using `framer-motion` and placeholder campfire images to enhance the entry experience. The main navigation menu was built and styled, and a reusable "Book" overlay system, complete with global state management via React Context, was created to house future content.
