# How to Update Your Portfolio Content

This guide will walk you through the simple steps to update the content of your portfolio website. You don't need to be a developer to do this!

## 1. Locating the Content File

All the project information displayed on your website is stored in a single file called `content.json`. You can find this file in the main folder of your project.

There's also a file named `content.example.json` which you can use as a reference to see how the content should be structured.

## 2. Editing `content.json`

You can open and edit `content.json` using any basic text editor (like Notepad on Windows, TextEdit on Mac, or VS Code if you have it).

The `content.json` file contains a list of your projects. Each project has its own section with details like:

*   `"title"`: The name of your project.
*   `"description"`: A short explanation of your project.
*   `"status"`: Whether the project is `"completed"`, `"in-progress"`, or `"available"`.
*   `"currentlyWorking"`: Set to `true` if you are actively working on it, `false` otherwise.
*   `"lastCommit"`: The date of your last update (e.g., `"2025-11-07T10:30:00Z"`).
*   `"technologies"`: A list of technologies used (e.g., `"React"`, `"TypeScript"`).
*   `"links"`: Links to the live demo (`"live"`) and GitHub repository (`"github"`).
*   `"image"`: The path to an image for your project (e.g., `"/projects/my-project.png"`).
*   `"jewelSlots"`: A list of "jewels" (skills) associated with the project.

**Important**: Make sure to keep the correct format! Pay attention to commas (`,`), quotation marks (`"`), and square brackets (`[]`) or curly braces (`{}`). If you're adding a new project, copy an existing project's structure and fill in your details.

Here's a simplified example of what a project entry looks like:

```json
{
  "title": "My Awesome Project",
  "description": "This project does amazing things using modern web technologies.",
  "status": "completed",
  "currentlyWorking": false,
  "lastCommit": "2024-01-15T14:00:00Z",
  "technologies": [
    "HTML",
    "CSS",
    "JavaScript",
    "MyCoolFramework"
  ],
  "links": {
    "live": "https://myawesomeproject.com",
    "github": "https://github.com/yourusername/myawesomeproject"
  },
  "image": "/projects/my-awesome-project.png",
  "jewelSlots": [
    { "jewel": "Frontend Development", "slotNumber": 1 },
    { "jewel": "UI/UX Design", "slotNumber": 2 }
  ]
}
```

## 3. Updating the Website

After you've saved your changes to `content.json`, you need to run a special command to update the content on your website.

1.  **Open your Terminal/Command Prompt**:
    *   On Windows, search for "Command Prompt" or "PowerShell".
    *   On Mac, search for "Terminal".
2.  **Navigate to your project folder**:
    *   Use the `cd` command. For example: `cd C:\Users\YourName\Desktop\your-portfolio-project`
3.  **Run the update command**:
    ```bash
    npm run update-content
    ```
    This command will process your `content.json` file and update the website's data.

**Do NOT edit the `public/data.json` file directly.** This file is automatically generated by the `npm run update-content` command.

## 4. Verification

After running the `npm run update-content` command, you can check your local website to make sure your changes are reflected correctly. If you have a development server running (`npm run dev`), it should automatically refresh with the new content.
